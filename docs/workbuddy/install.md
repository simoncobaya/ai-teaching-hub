# 安装指南

本文介绍 WorkBuddy 桌面客户端的安装方法，支持 **Windows** 和 **macOS** 两大平台。

---

## 系统要求

| 操作系统 | 支持版本 | 备注 |
|---------|---------|------|
| **Windows** | Windows 10 及以上 | ❌ 不支持 Windows 7 / 8 / 8.1 |
| **macOS** | macOS 12（Monterey）及以上 | 支持 Apple Silicon（ARM64）和 Intel（X64） |

> ⚠️ 不满足要求的系统将**无法启动** WorkBuddy。

### 如何查看 macOS 系统版本

点击左上角 **菜单栏（🍎）→「关于本机」**，查看 macOS 版本号：

![查看 macOS 系统版本](./images/mac-system-version.png)

如版本低于 12，需先升级 macOS。

---

## 下载

| 版本 | 下载地址 |
|------|---------|
| 🇨🇳 国内版 | <https://www.workbuddy.cn/> |
| 🌍 国际版 | <https://www.workbuddy.ai/> |

> 💡 国内版和国际版使用**同一个安装包**，安装步骤完全一致，仅**登录方式不同**（详见各平台「登录」步骤）。

打开官网首页，点击 **「下载」** 按钮，根据操作系统选择对应版本：

![官网下载页面](./images/win-download.png)

> 💡 **macOS 用户**：需根据处理器类型选择 **ARM64**（Apple Silicon：M1/M2/M3/M4）或 **X64**（Intel 芯片）。点击 **「关于本机」** 可查看芯片类型。

## Windows 安装

### Step 1：运行安装程序

双击下载好的 `.exe` 安装包：

![Windows 安装 — 启动](./images/win-install-1.png)

### Step 2：同意许可协议

选择 **「我同意此协议」**，点击「下一步」：

![Windows 安装 — 许可协议](./images/win-install-2-license.png)

### Step 3：选择安装位置

确认或修改安装路径，点击「下一步」：

![Windows 安装 — 选择路径](./images/win-install-3-path.png)

### Step 4：选择附加任务

可选择在开始菜单创建快捷方式：

![Windows 安装 — 开始菜单](./images/win-install-4-startmenu.png)

### Step 5：创建桌面快捷方式

可选择在桌面创建快捷方式：

![Windows 安装 — 桌面快捷方式](./images/win-install-5-shortcut.png)

### Step 6：确认安装信息

确认安装信息无误，点击 **「安装」**：

![Windows 安装 — 确认](./images/win-install-6-confirm.png)

### Step 7：安装完成

等待安装进度条完成，点击 **「完成」**：

![Windows 安装 — 完成](./images/win-install-7-complete.png)

### Step 8：登录

> 📌 国内版和国际版安装步骤完全一致，但**登录方式不同**。

启动 WorkBuddy，点击 **「登录」** 按钮：

![Windows 登录按钮](./images/win-login-1-button.png)

#### 🇨🇳 国内版 — 微信扫码

使用**微信**扫描弹出的二维码完成登录：

![微信扫码登录](./images/win-login-2-wechat-qr.png)

#### 🌍 国际版 — Google / GitHub / 邮箱

国际版登录界面提供以下三种方式，选择其中一种即可：

| 方式 | 说明 |
|------|------|
| **Google 登录** | 点击 **「Sign in with Google」**，跳转到 Google 授权页面，选择 Google 账号完成登录 |
| **GitHub 登录** | 点击 **「Sign in with GitHub」**，跳转到 GitHub 授权页面，授权后完成登录 |
| **邮箱登录** | 输入邮箱地址，点击发送验证码，输入收到的验证码完成登录 |

> ⚠️ 国际版**不支持微信登录**，请提前准备好 Google 账号、GitHub 账号或可用邮箱。

登录成功后，即可开始使用：

![登录成功](./images/win-login-3-success.png)

## 更新

### 方法一：通过客户端检查更新

1. 点击客户端 **右上角的「账户」图标**
2. 选择 **「检查更新」**

![检查更新](./images/win-update.png)

3. 如有新版本，按提示完成更新；如已是最新版本，会提示无需更新：

![已是最新版本](./images/win-update-latest.png)

### 方法二：重新下载安装

访问官网下载最新安装包，直接覆盖安装即可，数据不会丢失。

## 常见问题

### Q：Windows 7 / 8 能安装吗？

**不能。** WorkBuddy 仅支持 Windows 10 及以上版本。

### Q：macOS 提示"无法验证开发者"怎么办？

在 **「系统设置 → 隐私与安全性」** 中，找到关于 WorkBuddy 的提示，点击 **「仍要打开」**。

### Q：国内版和国际版账号能互通吗？

**不能。** 国内版（workbuddy.cn）和国际版（workbuddy.ai）是独立产品，账号不互通。
