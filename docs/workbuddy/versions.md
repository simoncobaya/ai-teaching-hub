# 国内版 vs 国际版

WorkBuddy 分为**国内版**和**国际版**两个独立产品，分别面向不同地区用户。

---

## 基本信息

| | 国内版 | 国际版 |
|---|--------|--------|
| **官网** | <https://www.workbuddy.cn/> | <https://www.workbuddy.ai/> |
| **上线时间** | 2026-03 | 2026-05 |
| **网络要求** | 国内直接访问 | 首次访问需国际网络 |
| **目标用户** | 中国大陆用户 | 全球用户 |

---

## 登录方式

| | 国内版 | 国际版 |
|---|--------|--------|
| **个人登录** | 微信扫码 | Google / GitHub / 邮箱注册 |
| **企业登录** | 企业微信、腾讯统一身份 | 企业 SSO |

---

## 内置模型

| | 国内版 | 国际版 |
|---|--------|--------|
| **模型** | DeepSeek、GLM、混元、Kimi-K3 | Claude、GPT-5、Gemini |

> 模型列表会持续更新，以官网实际提供为准。

---

## 生态集成

| | 国内版 | 国际版 |
|---|--------|--------|
| **办公生态** | 腾讯文档、微信、企业微信、飞书、钉钉 | Slack、Telegram、Discord、Notion |
| **代码托管** | GitHub、GitCode | GitHub、GitLab |
| **浏览器** | Chrome / Edge 插件 | Chrome 插件 |

---

## 账号互通

| 问题 | 答案 |
|------|------|
| 国内版账号能登录国际版吗？ | ❌ 不能，两套独立账号体系 |
| 国际版账号能登录国内版吗？ | ❌ 不能 |
| 数据能在两个版本间同步吗？ | ❌ 不能 |

> 两个版本是**完全独立的产品**，账号、数据、订阅均不互通。

---

## 如何选择

| 你的情况 | 推荐版本 |
|---------|---------|
| 在中国大陆，日常使用微信办公 | 🇨🇳 国内版 |
| 需要使用 DeepSeek / 混元等国内模型 | 🇨🇳 国内版 |
| 需要与腾讯文档 / 企业微信集成 | 🇨🇳 国内版 |
| 在海外或有国际网络环境 | 🌍 国际版 |
| 需要使用 Claude / GPT-5 / Gemini | 🌍 国际版 |
| 需要与 Slack / Notion / GitHub 集成 | 🌍 国际版 |
