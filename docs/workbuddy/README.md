# WorkBuddy（腾讯 AI 办公助手）

> WorkBuddy 是腾讯推出的**全场景 AI 办公工作台**，基于 Agent 框架构建，具备自然语言理解、自主规划、多模态任务处理和本地文件操作能力。2026 年 3 月正式发布。

---

## 产品定位

WorkBuddy 与 CodeBuddy 同属腾讯 AI 工具生态，但定位不同：

| | CodeBuddy | WorkBuddy |
|---|-----------|-----------|
| **定位** | AI 编程助手 | AI 办公助手 |
| **核心场景** | 代码编写、补全、调试 | 文档生成、数据分析、PPT 制作 |
| **产品形态** | IDE / 插件 / CLI | 桌面客户端 |
| **面向用户** | 开发者 | 职场办公人群 |

---

## 核心能力

| 能力 | 说明 |
|------|------|
| **自然语言理解** | 用大白话描述需求，AI 自动理解并执行 |
| **自主规划** | 复杂任务自动拆解步骤，逐步完成 |
| **多模态任务处理** | 支持文本、图片、文件等多种输入 |
| **本地文件操作** | 直接读取、创建、修改电脑上的文件 |
| **联网搜索** | 自主上网检索最新信息 |

---

## 典型使用场景

| 场景 | 示例 |
|------|------|
| **文档生成** | "帮我写一份 Q3 季度工作总结" |
| **数据分析** | "分析这份 Excel 销售数据，找出增长趋势" |
| **PPT / 报告生成** | "根据这份项目计划书，生成一份汇报 PPT" |
| **深度研究** | "调研 2026 年 AI 编程工具市场格局" |
| **邮件编辑** | "帮我回复这封客户邮件，语气专业礼貌" |
| **批量文件处理** | "把这 10 个 Word 文档合并成一个 PDF" |

---

## 与传统 AI 对话工具的区别

| | 传统 AI 对话 | WorkBuddy |
|---|-------------|-----------|
| **交互方式** | 一问一答，需手动复制结果 | 自主执行，直接产出文件 |
| **文件处理** | 仅文本交互 | 直接操作本地文件 |
| **任务复杂度** | 单轮对话 | 多步骤自主规划执行 |
| **结果交付** | 文字回复 | 生成文档、表格、PPT 等 |

## 国内版与国际版

WorkBuddy 有两个独立的官网和账号体系：

| 版本 | 官网 | 上线时间 | 内置模型 |
|------|------|----------|----------|
| **国内版** | <https://www.workbuddy.cn/> | 2026-03 | DeepSeek、GLM、混元、Kimi-K3 |
| **国际版** | <https://www.workbuddy.ai/> | 2026-05 | Claude、GPT-5、Gemini |

> 国内版和国际版是**独立产品**，账号不互通。国内版通过微信登录，国际版通过 Google / GitHub / 邮箱注册。

详见 **[国内版 vs 国际版](./versions.md)**。
