## 🎮 游戏课程说明（第七、八步）

第七、八步用**一个游戏的两个阶段**带你入门游戏开发：

| 课次 | 阶段 | 核心理论 | 控制机制 |
|:---:|------|---------|---------|
| [第七步](./07-whack-a-mole.md) | 🔨 从零到能玩 | 游戏循环 + 点击检测 + 状态机 + 计分 | 🧩残缺代码 · 📝填空提示词 · ✏️画状态图 |
| [第八步](./08-game-feel.md) | ✨ 从能玩到好玩 | Game Feel + 粒子系统 + 缓动 + 音效 | 🎭对比实验 · ✏️效果设计表 · 🎨playground |

**特点**：
- 一个游戏串起全部概念——不是"给 AI 一句话拿到游戏"，而是**你设计，AI 写代码，你测试，你迭代**
- 用 **Python + Pygame** 做真正的桌面应用（不是网页版！）
- 同一个游戏迭代两次，感受"能用"到"好玩"的改造力量

**课前准备**（第七步开始前确保）：
- [x] 安装了 Plugin：
  ```
  /plugin install frontend-design@claude-plugins-official
  /plugin install superpowers@claude-plugins-official
  /plugin install playground@claude-plugins-official
  ```
- [x] Output Style 设为 **Explanatory**：`/config → Output Style → Explanatory`
- [x] 电脑上有 Python（第七步会安装 Pygame）
