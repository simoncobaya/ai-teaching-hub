# ✨ 第2课：疯狂打地鼠 — 从能玩到好玩

> 同一个游戏，同一个玩法。加上这些小魔法，从"能用"变成"停不下来" 🪄

---

## 🎯 目标

在第1课的"干巴巴版"打地鼠基础上，学会：

- ✅ Game Feel — 什么是"游戏手感"，为什么它比玩法本身更重要
- ✅ 粒子系统 — 打中爆出彩色碎片
- ✅ 缓动动画 — 地鼠弹出来而不是突然出现
- ✅ 屏幕震动 + 音效 — 打到炸弹时"全身一震"

---

## 📖 理论：Game Feel 是什么？

### 同一个游戏，两个版本

```
❌ 干巴巴版（第1课做出来的）：
  点中地鼠 → 地鼠消失 → 分数 +10
  就这样。没了。玩 30 秒觉得无聊 😴

✅ 魔法版（这节课要做的）：
  点中地鼠 → 💥 橙色粒子爆炸 → "+10"飘起来飞走
  地鼠出来时"弹"一下（从小到大）
  连击 3 次 → 🔥 "COMBO!" 金色大字
  打到炸弹 → 屏幕一震 → "嘭！"音效
  不知不觉玩了 10 分钟 🤩
```

**玩法一模一样！区别只在"手感"——那些让你觉得爽的视觉和听觉反馈。**

### 四大魔法

| 魔法 | 是什么 | 打地鼠里怎么用 |
|------|--------|--------------|
| ✨ **粒子** | 大量小图形短暂飞散消失 | 打中地鼠 → 彩色碎片向四周爆炸 |
| 🎬 **缓动** | 物体不突然变化，而是"弹"到目标 | 地鼠从小弹到大（弹性冒出） |
| 📳 **震动** | 画面短暂抖动 | 打到炸弹时震一下 |
| 🔊 **音效** | 动作的声音反馈 | 打中="啵"，连击="叮叮叮"，炸弹="嘭" |

## 🎮 动手：从干巴巴到魔法版

### ⚠️ 控制机制

> **先用第1课的版本玩 1 分钟，写"无聊清单"。然后从效果菜单中自己选至少 3 种来添加。**

---

### Step 1：玩 30 秒，写无聊清单 📋

运行第1课做的 `python whack_a_mole.py`，玩 30 秒。写下你觉得"不够爽"的地方：

- [ ] 打中时地鼠直接消失——没感觉
- [ ] 分数只是数字跳动——不刺激
- [ ] 没打中没有反馈——不知道是慢了还是快了
- [ ] 倒计时结束得太突然——没结算感
- [ ] 连击提示太低调——不够燃
- [ ] （你自己的感受）

### Step 2：选择你要加的效果

从下面的"魔法菜单"中，**选择至少 3 种**：

| # | 效果 | 触发时机 | 难度 |
|:--:|------|---------|:--:|
| 1 | ✨ **粒子爆炸** | 打中地鼠时 | 🌱 |
| 2 | 🎬 **弹性冒出** | 地鼠出现时 | 🌱 |
| 3 | 💯 **浮动分数** | 打中地鼠时 "+10" 飘上去 | 🌱 |
| 4 | 📳 **屏幕震动** | 打到炸弹时 | 🌱 |
| 5 | 🔥 **连击特效** | 连续打中 3/5/7 次时 | 🌿 |
| 6 | 🎯 **光标特效** | 点击时扩散圈 | 🌱 |
| 7 | ⚡ **完美时机** | 地鼠刚冒出 0.2 秒内打中="PERFECT!" 双倍分 | 🌿 |
| 8 | 🔊 **音效** | 打中、连击、炸弹、倒计时 | 🌿 |

> ⚠️ **选好后填效果设计表（在纸上或笔记里）**，再逐个让 AI 实现。AI 不能替你选——这是你的设计。

```
效果设计表：
| 编号 | 效果 | 触发时机 | 我想让它看起来/听起来像…… |
|:--:|------|---------|------------------------|
| 1 | 粒子 | 打中时 | 橙色碎片爆开，像烟花 |
| 2 | … | … | … |
```

> 🎨 **风格统一小贴士**：先定一个主题色板（2-3 种颜色），所有效果都从色板里取色。比如"草地主题"→ 深绿背景 + 亮绿粒子 + 棕色地鼠；"夜晚主题"→ 深蓝背景 + 金色粒子。如果粒子是彩虹色、地鼠是红色、背景是白色——看起来就像打翻了颜料桶 🎨。字体也一样：标题和分数用一个风格，别混用默认字体。

### Step 3：用 playground 设计粒子 🎨

```
帮我用 /playground 做一个粒子效果设计器。
可调参数：粒子数量(5-30)、颜色(暖色/冷色/彩虹)、
飞行速度(慢/中/快)、大小(小/中/大)、存活时间。

我调好参数后复制 prompt 回来。
```

（playground 在浏览器打开，调游戏参数没问题）拖到满意 → 复制 prompt → 发给 Claude Code：

```
[粘贴 playground prompt]

请根据这个参数，在我的打地鼠游戏里添加粒子效果：
- 地鼠被点击时，在点击位置粒子爆炸
- 每个粒子飞向随机方向
- 随生命值减少逐渐变透明
- 全部消失后自动清除
```

### Step 4：逐个实现你选的效果

> 💡 **一次只加一个效果。** 加一个 → 测试 → 满意 → 再加下一个。

每加完一个告诉 AI：

```
粒子效果做好了。接下来帮我加 [你选的下一个效果]：
[描述触发时机和你想要的样子]

请只加这个功能，不要动已经做好的粒子效果。
```

### Step 5：加音效 🔊

```
帮我的打地鼠用 Pygame 的 mixer 模块生成音效（用代码生成，不需要音频文件）：
- 打中地鼠："叮！"（短促高音，~0.1秒）
- 连击触发："叮叮叮！"（音调递增，三次不同音高）
- 误打炸弹："嘭…"（低沉短音）
- 倒计时最后5秒：每秒一个短促"滴"声
- 游戏结束：一小段下行音阶

纯代码生成，不下载任何文件。
需要用 numpy 生成波形数组，再用 pygame.sndarray.make_sound() 转成音效。
如果电脑没有音频设备（比如用远程桌面玩），游戏要能自动静音、继续正常运行。
```

> 💡 这一步需要 numpy 库（第 1 课安装时已经一起装好了）。「叮」「嘭」这些声音不是下载的，而是用数学公式现场算出来的——频率高低、长短、衰减快慢都可以精确控制。

### Step 6：前后对比

| 对比维度 | 第1课的版本 | 现在 |
|---------|-----------|------|
| 打中地鼠时 | 地鼠消失 | |
| 地鼠出现时 | 突然出现 | |
| 连击时 | 小字提示 | |
| 没打中/打到炸弹 | 无反应 | |
| 倒计时最后5秒 | 只有数字变 | |

### Step 7：打包，发给朋友玩！📦

游戏做完了，只在自己电脑上跑 = 还没做完。真正的游戏要**别人也能打开玩**。用 Pygame 写好的游戏可以用 PyInstaller 打包成独立程序，双击就能玩，不需要安装 Python。

**两种方式，选一种：**

**方式一：直接让 Claude Code 打包（推荐！）**

在 Claude Code 里说：

```
帮我把 whack_a_mole.py 打包成独立程序，发给朋友玩。
用 pyinstaller，参数 --onefile --windowed。
打包完告诉我文件在哪里、怎么发给别人。
```

Claude Code 会自动安装 pyinstaller 并运行打包命令（如果它问"是否允许运行命令"，点允许），最后告诉你打包好的文件在哪。

**方式二：自己在终端打包（想学命令的同学）**

打开**终端**（不是 Claude Code 里面），先安装打包工具：

```bash
pip install pyinstaller
```

然后进入你的项目文件夹，打包：

```bash
pyinstaller --onefile --windowed whack_a_mole.py
```

> 💡 `--onefile` = 打包成一个单独的文件（不加的话会生成一大文件夹）；`--windowed` = 运行时**不弹黑色命令行窗口**——Python 程序默认带一个控制台窗口，你的朋友双击后看到黑框会以为坏了。副作用是报错信息也看不见了，所以调试阶段可以先不加 `--windowed`，最后发布时再加上。

打完之后，打开 `dist` 文件夹，里面就有打包好的文件：

| 你的系统 | 打包出来的文件 | 发给朋友什么 |
|---------|--------------|------------|
| Windows | `whack_a_mole.exe` | 发 `.exe` |
| macOS | `whack_a_mole`（无后缀） | 发这个文件（朋友可能需要在"系统设置 → 隐私与安全"里点"仍要打开"） |
| Linux | `whack_a_mole`（无后缀） | 发这个文件 |

> ⚠️ 打包出来的程序只能在**打包时用的系统**上运行：Windows 上打包 → 只能发给 Windows 的朋友。想发 macOS 的朋友，需要在 macOS 电脑上重新打包一次。

**发到班级群，然后收集反馈** 🎉：

```
我做的打地鼠游戏，玩玩看！
玩法：30 秒内点地鼠得分，别打炸弹 💣
[文件]
帮我反馈两个：1. 哪里好玩？2. 哪里想改？
```

这就是游戏开发的完整闭环：**做 → 玩 → 反馈 → 改进**。你的游戏真正"出生"了！

### 🌱 挑战 1：黄金地鼠 👑

```
添加"黄金地鼠"：

```

## ⚠️ 设计师须知：好游戏让人开心，不是让人停不下来

现在你是游戏设计师了 🎮 请记住设计师的责任：

**好的游戏设计让人开心、有成就感、还想再玩一次。坏的设计让人停不下来、忍不住一直玩、放下后心里空空的。**

下面这些机制是真实游戏里常见的"上瘾设计"，检查一下你有没有用过：

| 上瘾设计 | 它怎么"绑架"你 | 你的打地鼠里有吗？ |
|---------|--------------|:--:|
| 🎁 每日签到 | "不签到就亏了！"——用失去的恐惧逼你每天来 | |
| 🎰 随机奖励 | 抽卡、开箱——不确定的奖励让人忍不住一直抽 | |
| ⏰ 限时活动 | "只剩 3 小时！"——制造紧迫感让你立刻玩 | |

> 💡 打地鼠的连击、黄金地鼠这种设计是**好的**——它们让人开心，玩一局 30 秒就结束，不会把人绑住。好游戏和上瘾游戏的分界线是：**你玩完是"好开心！"还是"再来一局……就一局……"？**
>
> 你能做游戏，也能选择做一个让人开心的游戏。
