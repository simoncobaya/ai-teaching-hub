# 🔨 第1课：疯狂打地鼠 — 从零到能玩

> 一个游戏串起四个概念：游戏循环、点击检测、状态机、计分 🧠

---

## 🎯 目标

学完这一节，你将从零做出一个**能玩的桌面打地鼠游戏**，同时学会：

- ✅ 游戏循环 — 每秒 60 次"更新→绘制→重复"
- ✅ 点击检测 — 怎么判断"鼠标点到了地鼠"（碰撞检测的变体！）
- ✅ 状态机 — START → PLAYING → GAME_OVER 三个状态
- ✅ 计分系统 — 打中加分、连击翻倍

## 📖 理论一：游戏循环

### 翻页动画 📒

课本角落每页画个小人，每页变一点——快速翻页，小人跑起来了。游戏循环就是电子版：

```
🖼️ 画一帧 → 🔄 更新位置 → 🖼️ 画下一帧 → 🔄 再更新 → ...
一秒 60 次！快到眼睛以为画面在"动"。
```

### 三个步骤

| 步骤 | 打地鼠里做什么 |
|------|--------------|
| 1️⃣ **Update** | 计时器走一秒、地鼠该冒出来了、该缩回去了 |
| 2️⃣ **Draw** | 清窗口 → 画 9 个洞 → 画地鼠（如果有）→ 画分数 |
| 3️⃣ **Loop** | `clock.tick(60)` 控制每秒 60 帧 |

> 💡 游戏画面不是"修改"出来的，是每秒"重新画"60 次。

## 🎮 动手一：让游戏"动"起来

### 游戏介绍

9 个洞（3×3），地鼠随机冒出，用鼠标点击打中它。倒计时 30 秒，追求最高分。

### ⚠️ 控制机制

> **你拿到的代码少了关键逻辑！** 地鼠不会冒出来——因为生成逻辑被留空了。

### Step 2：先写一句话规则 ✏️

在让 AI 写代码之前，先像游戏设计师一样，把**规则**写清楚。试着填满这句话：

> 我要在 **__ 秒** 内尽量得高分：打中地鼠 **+__ 分**，连续打中会 **____**，打中炸弹 **____ 分**，时间结束比谁分高。

写不出来的地方（比如"打中炸弹会怎样"）先留空——那是你待会儿要做的设计决定。但有了这句话，AI 就知道你要什么，你也不会被 AI 牵着走。

> 💡 好的游戏规则一句话就能讲完。如果需要三句话以上，说明它太复杂了。

### Step 3：让 AI 创建残缺代码

把下面这段话**完整复制**到 Claude Code：

```
请帮我创建一个打地鼠游戏，用 Python + Pygame 实现。

窗口大小 600x600，标题 "疯狂打地鼠"。9个洞（3x3），每个洞是深色椭圆。

⚠️ 重要：地鼠的「随机出现逻辑」故意留空（代码中用 TODO 标注），
因为我想自己思考然后补全。其他功能要完整：

- 洞的位置固定（3×3 均匀排列，间距自己算）
- 倒计时 30 秒，时间到游戏结束
- 鼠标点击检测框架写好（能获取点击坐标和点击事件）——
  但点击先不要做任何反应（不加分、地鼠不消失），这些我后面再加
- 分数在窗口上方显示
- 游戏循环用 pygame.time.Clock，每秒 60 帧
- 所有代码放在一个 whack_a_mole.py 文件里

请让「地鼠随机出现」部分标注 TODO，不要实现。
```

### Step 4：找到 TODO

```
帮我找到代码里标注 TODO 的地方，解释一下这里应该有什么逻辑。
```

### Step 5：填空式提示词

> ⚠️ 把 `[ ]` 替换成你的想法，再发给 AI。

```
在 whack_a_mole.py 中，TODO 标记缺少「地鼠随机出现」的逻辑。请帮我补全：

1. 用一个计时器，每隔 [你填，比如 0.8~1.5] 秒让地鼠出现在随机洞口
2. 地鼠停留 [你填，比如 0.6~1.2] 秒后如果没有被打中就缩回去
3. 不能两只地鼠同时出现——一次只有一只
4. 地鼠缩回去后，随机间隔再出现在另一个洞
```

> 💡 填空的过程就是你在设计游戏节奏！太快=太难，太慢=太无聊。

## 📖 理论二：点击检测 = 碰撞检测

### 打地鼠的"碰撞"是什么？

碰撞检测不限于"两个游戏物体相撞"。它的本质是：**判断两个区域有没有重叠。**

```
┌─────────┐         判断两个盒子有没有碰到：
│  盒子A   │         1. A 的右边在 B 的左边的右边吗？
└─────────┘         2. A 的左边在 B 的右边的左边吗？
      ┌─────────┐   3. A 的下面在 B 的上面的下面吗？
      │  盒子B   │   4. A 的上面在 B 的下面的上面吗？
      └─────────┘
                    四个全"是"→ 碰到了！💥
```

打地鼠里，"盒子A"变成了**鼠标点击坐标**，"盒子B"是**地鼠的矩形区域**：

```python
# 通用碰撞公式（AABB）：
a.x < b.x + b.width and a.x + a.width > b.x and \
a.y < b.y + b.height and a.y + a.height > b.y

# 应用到鼠标点击 vs 地鼠：
mouse_x > mole.x and mouse_x < mole.x + mole.width and \
mouse_y > mole.y and mouse_y < mole.y + mole.height
```

> 💡 本质完全一样——判断两个区域有没有重叠。以后做射击游戏（子弹 vs 敌人）、跑酷游戏（角色 vs 障碍），用的都是这个公式。

## 🎮 动手二：让打中有反应

### Step 7：加点击检测

```
现在点击地鼠没有任何反应。请帮我添加点击检测：

1. 在 Pygame 事件循环中，监听 MOUSEBUTTONDOWN 事件
2. 获取点击的坐标 event.pos
3. 检查点击位置是否在当前地鼠的矩形范围内
4. 如果打中了：分数 +10，地鼠消失，等待下一只
5. 如果没打中（点空了）：什么都不发生

检测方法跟碰撞检测一样——判断两个矩形有没有重叠。
```

### Step 8：验证

运行 `python whack_a_mole.py`。打中=加分+地鼠消失。没打中=无反应。如果"明明点到了没反应"——把现象描述给 AI 定位修复。

## 📖 理论三：状态机

### 红绿灯 🚦

红绿灯永远是红/黄/绿之一，不会"又红又绿"。切换有规则：绿 30s→黄 3s→红。

游戏也一样：

```
┌──────┐  点击开始  ┌────────┐  倒计时到  ┌────────┐
│ START │ ────────→ │PLAYING │ ────────→ │GAME_OVER│
│ 标题  │           │ 30秒   │           │ 最终分  │
└──────┘           └────────┘           └───┬────┘
                        ↑                   │
                        └─── 点击重来 ──────┘
```

```
❌ 没有状态机：打开就开始玩，时间到画面停——没有开始感，没有结束感
✅ 有状态机：开始画面→紧张30秒→结算画面——完整游戏体验
```

## 🎮 动手三：加状态机

### ⚠️ 控制机制

> 当前游戏打开就直接玩（只有一个状态）。你要设计 START 和 GAME_OVER 两个状态。

### Step 9：在纸上画状态图 ✏️

画三个方框 + 箭头。在每个方框里写下：
- **START**：标题叫什么？什么颜色？提示按什么开始？
- **PLAYING**：保持现有逻辑
- **GAME_OVER**：显示什么结束语？分数怎么展示？按什么重来？
- **箭头**：每条标注触发条件

### Step 10：用 AI 实现

```
我的游戏目前只有一个状态（打开就玩）。请按我的设计添加状态机：

START 状态：
- 显示 [你的标题]，背景 [你的颜色]
- 提示 "点击开始游戏"
- 点击后切换到 PLAYING

PLAYING 状态：
- 保持现有逻辑（30秒倒计时、地鼠出现、点击检测）
- 倒计时到 0 → 切换到 GAME_OVER

GAME_OVER 状态：
- 显示 [你的结束语] 和最终分数
- 提示 "点击重新开始"
- 点击后切换到 PLAYING（分数归零、计时器重置）

用一个 game_state 变量（比如 "start" / "playing" / "gameover"）区分不同状态。
```

### Step 11：加计分增强

```
现在打中地鼠固定 +10 分。请帮我加上连击加分：
- 连续打中（中间没有 miss）第 3 只、第 5 只、第 7 只……额外 +5 分
- 在窗口上方显示 "🔥 COMBO x3!" （只显示 1 秒然后消失）
- 如果没打中（地鼠自己缩回去了），连击中断

提示：用一个 streak 变量记录连续打中次数。地鼠缩回去时 reset 为 0。
```

> 💡 如果 `🔥` 在你的电脑上显示成方块 □（有些系统字体不支持 emoji），就让 AI 换成文字或画一个图形火焰代替。

## 🧪 动手四：找人玩 1 分钟

### Step 12：测试！让别人玩 🧐

游戏"看起来"完成了？真正的检验刚刚开始。**做游戏的人是自己最差的测试员**——你知道所有机制，所以你看不出哪里难懂；别人第一次玩，什么问题都藏不住。

找一个同学（或者爸爸妈妈），让他玩你的游戏 **1 分钟**。你**只做记录，不帮忙、不提示**。用这个清单观察：

| 你观察什么 | 记下来 |
|-----------|-------|
| 😕 他不知道怎么开始吗？ | |
| 🖱️ 他点了哪里？点对地方了吗？ | |
| 🐢 他觉得地鼠出来太快/太慢？ | |
| ❓ 他问过什么问题？ | |
| 😄 他什么时候笑了/觉得爽？ | |
| 😐 他什么时候走神了/不想玩了？ | |

看完问 TA 三个问题：

1. 你觉得这游戏哪里最好玩？
2. 哪里让你觉得无聊/困惑？
3. 如果能改一个地方，你改哪里？

> 💡 专业游戏公司做游戏时，每周都做这样的"玩家测试"。玩家的回答，比你自己盯着屏幕猜准 100 倍。
>
> 把 TA 说的最有价值的一条，告诉 AI 帮你改进。比如"测试的人觉得地鼠出来太慢，等了 3 秒才出来，帮我加快一点"。

## 🌟 进阶挑战

### 🌱 挑战 1：加速机制

```
让游戏越来越快：
- 时间还剩 20 秒以上：地鼠出现间隔 [你填]，停留 [你填]
- 时间还剩 10-20 秒：间隔缩短 30%，停留缩短 20%
- 时间最后 10 秒：间隔缩短 50%，停留缩短 40%

用剩余时间判断当前速度。
```

### 🌿 挑战 2：炸弹地鼠

```
添加一只"炸弹地鼠"：
- 每 8-12 秒随机出现在某个洞
- 红色，身上有 💣 标记
- 停留时间只有正常地鼠的一半
- 打中扣 20 分 + 屏幕闪红一下
- 如果误打了，连击不中断（因为是"打中了东西"）
```

## 🧗 讨论：高手怎么玩这个游戏？

好游戏都有一个共同点——**易学难精**：

```
新手：点中地鼠 → 加分 → 开心 😄
高手：只在「完美时机」点 → 连击不断 → 一次不 miss → 冲刺最高分 🤯
```

同一个游戏，新手 1 分钟就能玩，高手玩 100 遍还有挑战。这就是"易学难精"。

想一想，你的打地鼠**给高手留了什么追求**？

- [ ] 连续打出 20+ 连击
- [ ] 一局下来 0 次 miss
- [ ] 找到最快的地鼠出现节奏，卡着点打
- [ ] 挑战同学的最高分

> 💡 如果你的游戏新手能玩、高手还能追求更多——它就是"易学难精"。做游戏时想想：我给高手准备了什么？
